## Featured work

### 🍕 [Pizza Expert](https://github.com/shayan2601/pizza-expert) · [live ↗](https://pizza-expert.vercel.app)

A full-stack ordering platform: storefront, cart, guest checkout, order tracking, and an admin dashboard for menu management and fulfilment.

Built as a monorepo — **Next.js 16 / React 19** client and a **NestJS 11** API over **MongoDB**. Authorization is enforced server-side with JWT plus a roles guard, so admin routes stay protected regardless of what the client renders. Order line items snapshot product name and price at purchase time, so historical orders don't shift when the menu is repriced.

`Next.js` `React 19` `TypeScript` `NestJS` `MongoDB` `JWT` `Tailwind CSS 4`

### 🎨 [CultureUp](https://github.com/shayan2601/culturup) · [live ↗](https://culturup.vercel.app)

A marketplace connecting artists with buyers — artwork discovery and sales, an equipment marketplace, a freelance jobs board, in-app messaging, and Stripe checkout.

**React 19 + Vite** SPA consuming a Django REST API. Includes an auction bidding flow, two-factor authentication with backup-code recovery, and an admin dashboard with Recharts analytics behind a protected route.

`React 19` `Vite` `Tailwind CSS 4` `Stripe` `React Router 7` `Recharts` `Framer Motion`
